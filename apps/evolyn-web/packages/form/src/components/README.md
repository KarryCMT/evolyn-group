# 表单中心组件说明

本文档用于说明当前目录下表单中心相关组件的中文名和主要职责，方便后续维护时快速定位文件。

## 表单编辑入口

| 组件                     | 中文名       | 主要职责                                                                                                                 |
| ------------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------ |
| `FormDesignCanvas.vue`   | 表单编辑抽屉 | 表单新增、编辑的主抽屉，包含表单属性表单和表单设计两个页签，并负责表单详情加载、属性保存、设计保存和与所属表单配置同步。 |
| `PluginDrawerHeader.vue` | 表单抽屉头部 | 抽屉顶部通用头部，提供返回/关闭按钮、可编辑标题和页签切换。                                                              |

## 设计器主体

| 组件                            | 中文名           | 主要职责                                                                                                                                                |
| ------------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PluginDesignPanel.vue`         | 表单设计器主面板 | 表单设计器总装组件，维护设计数据、当前函数、菜单、字段选择、身份验证字段选择、保存/调试入口，并串联侧栏、字段面板、画布、代码视图、属性面板和调试抽屉。 |
| `PluginDesignToolbar.vue`       | 表单设计器工具栏 | 设计器顶部工具栏，展示当前标题、保存状态，提供运行环境/视图模式切换，以及保存、保存并调试操作。                                                         |
| `PluginDesignSidebar.vue`       | 表单设计器侧栏   | 左侧导航和函数管理区域，展示根菜单、前端扩展、后端函数，支持选择菜单、函数排序、新增、编辑、复制、删除函数。                                            |
| `PluginDesignPalette.vue`       | 字段组件面板     | 字段素材栏，展示当前菜单可添加的字段类型，支持点击添加和拖拽克隆字段到画布。                                                                            |
| `PluginDesignCanvas.vue`        | 字段设计画布     | 通用参数/请求参数的表单字段画布，支持字段拖拽排序、选择、复制、删除、默认值编辑，以及对子表单字段的嵌套画布渲染。                                       |
| `PluginDesignPropertyPanel.vue` | 字段属性面板     | 右侧字段属性配置面板，编辑字段显示名称、ID、提示、必填、默认值、下拉选项；对子表单字段会切换到子字段管理和子字段属性配置。                              |

## 字段与参数

| 组件                               | 中文名         | 主要职责                                                                                                    |
| ---------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------- |
| `PluginDesignFieldControl.vue`     | 字段默认值控件 | 根据字段类型渲染默认值输入控件，支持普通输入、下拉框、成员/部门选择器，并统一输出表单字段需要的默认值结构。 |
| `PluginDesignResponseParams.vue`   | 返回参数配置   | 返回参数表格配置组件，支持新增一级返回参数、递归编辑 vector 子参数、编辑名称/ID/类型和删除参数。            |
| `PluginDesignResponseParamRow.vue` | 返回参数递归行 | 单个返回参数行组件，递归渲染 vector 的 `fieldConf.fields`，并透传新增、删除和类型切换操作。                 |

## 子表单字段

| 组件                                | 中文名               | 主要职责                                                                                                              |
| ----------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `FormSubformCanvas.vue`             | 子表单画布           | 子表单/向量字段的表格化预览画布，支持从字段面板拖入子字段、选择、复制、删除子字段，并按子字段类型展示禁用态预览控件。 |
| `FormSubformFieldPanel.vue`         | 子表单字段列表       | 右侧子表单子字段管理组件，支持新增文本、数字、日期时间、下拉、成员、部门子字段，以及排序、选择、复制、删除。          |
| `FormSubformChildPropertyPanel.vue` | 子表单子字段属性面板 | 子表单子字段属性配置组件，编辑显示名称、ID、提示、必填/隐藏/启用、文本类型、下拉选项和默认值。                        |

## 子表单运行时赋值

| 目录                    | 主要组件                                       | 说明                                                                                                      |
| ----------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `form-subform-renderer` | `FormSubformTable.vue` / `FormSubformCell.vue` | 表单节点的子表单逐行赋值功能，拆分表格、单元格、行编辑抽屉和状态 hook；仅支持自定义值与字段值两种列模式。 |

## 代码编辑与调试

| 组件                     | 中文名         | 主要职责                                                                                                                           |
| ------------------------ | -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `FormCodeEditor.vue`     | 表单代码编辑器 | 基于 Monaco Editor 的代码编辑器封装，支持 JavaScript、Python、Java、JSON 高亮，运行时变量/代码片段补全、只读模式、诊断标记和定位。 |
| `FormDesignCodeView.vue` | 表单代码视图   | 函数代码编辑区，按运行环境切换编辑语言，展示代码诊断；在代码页展示参数结构侧栏，在参数页编辑 JSON，并在校验成功后同步回表单配置。  |
