# Embedded label font

`NotoSansSC-VF.ttf` is the platform-registered Simplified Chinese label font.
It is distributed under the SIL Open Font License 1.1 included in `OFL.txt`.

Upstream family: Noto Sans CJK / Noto Sans SC  
Project: https://github.com/notofonts/noto-cjk

The renderer embeds the font so Linux, Windows, worker, PNG and PDF output use
the same glyph source instead of depending on fonts installed on the host.
