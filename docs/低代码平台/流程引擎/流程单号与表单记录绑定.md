# 流程单号与表单记录绑定

流程单号是不可变的业务标识，不使用数据库主键，也不是用户可编辑控件。

- 格式：`WF-YYYYMMDD-NNNNNN`，例如 `WF-20260905-000001`。日期取数据库东八区时间；租户内每日递增，流水至少六位，超过六位自动扩展。
- 唯一范围：租户。查询和业务关联始终包含租户上下文，单号本身不是授权凭据。
- 生成：实例创建仓储通过计数器表的原子 UPSERT 分配，禁止 `MAX+1`、客户端生成和用实例 ID 拼接。
- 实例保存 `wf_instance.instance_no`；流程型表单记录独立保存 `tn_form_records.workflow_instance_no`。普通表单为空，不放入用户 `values` JSONB。
- 提交记录、分配单号、创建实例/任务、绑定记录单号共用一个事务，任一步失败全部回滚。相同提交幂等键返回原记录及原单号，不重复发起。撤回、退回、重提交不修改已有实例单号。
- 提交结果和表单记录列表返回 `workflowInstanceNo`；流程实例、任务列表及详情返回 `instanceNo`。前端表格投影为只读 `sys.workflowInstanceNo` 列，流程卡片和审批详情展示单号。
- 迁移 000068 为历史实例按租户、东八区创建日期和创建顺序补号，并将计数器推进到历史最大流水。对应表单记录绑定最早实例；没有流程实例的旧记录保留空值，不自动发起流程。

上线须先应用版本化 SQL 迁移。回滚迁移会移除单号数据，不应作为常规应用版本回退方式。
