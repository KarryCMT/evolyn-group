# 账号安全与会话体系任务清单（ADR-009）

> 对应方案：[账号安全与会话体系设计方案.md](./账号安全与会话体系设计方案.md)。
> 进度跟踪：完成后勾选；重大变更回链方案文档。

## 任务清单

### 第 1 步：数据层（本批）

- [x] **SEC-1-1 迁移 000019**：`account_security_settings` / `account_mfa_factors` /
      `account_mfa_recovery_codes` / `account_sessions` / `account_security_events`
      五表 up/down（平台级、无 tenant_id；约束/索引命名与迁移一致保证快照重放幂等）。
- [x] **SEC-1-2 GORM 模型与仓储**：`internal/platform/auth/security/{model,repository}`，
      仓储含 settings 读写、因子生命周期、恢复码摘要消费、会话创建/撤销/
      撤销他人/Touch/列表、安全流水追加。
- [x] **SEC-1-3 db.sql 同步**与迁移断言更新（版本 18→19、文件 36→38）。

### 第 2 步：security 子域 API 骨架

- [x] **SEC-2-1** controller → service → repository 三层与 server 装配；
      `GET /accounts/me/security`、`GET/DELETE /accounts/me/sessions(/:id)` 只读先通。

### 第 3 步：会话化登录链路

- [ ] **SEC-3-1** JWT 增加 `sid`/`sessionTokenVersion`；认证中间件校验
      `account_sessions` 未撤销且版本一致（Redis 短缓存，撤销即时失效）。
- [ ] **SEC-3-2** 登录/注册/OAuth/短信统一走会话签发器；登出撤销 `sid`；
      租户切换复用 `sid` 递增 `token_version`。
- [ ] **SEC-3-3** 禁止同时登录：登录事务内锁账号行 → 撤销其他活跃会话 →
      建新会话；被挤出请求返回 `AUTH_SESSION_REPLACED`。
- [ ] **SEC-3-4** 会话清理 Worker（过期/撤销会话定期归档删除）。

### 第 4 步：TOTP MFA

- [ ] **SEC-4-1** TOTP 算法与密钥加密（主密钥生产配置注入 + key_version 轮换）。
- [ ] **SEC-4-2** enroll/confirm/关闭链路 + 恢复码生成/摘要存储/一次性消费。
- [ ] **SEC-4-3** 挑战式登录第二步：Redis `mfaChallenge`（5 分钟/单次/限次），
      `POST /auth/mfa/verify`；OAuth/短信入口同样过第二步。
- [ ] **SEC-4-4** 高风险操作 reauth（`POST /accounts/me/security/reauth`）与
      密码/手机号/MFA 变更撤销其他会话。

### 第 5 步：前端

- [ ] **SEC-5-1** 解除 AccountSecurityPanel 两个禁用开关，接 `PUT` 接口。
- [ ] **SEC-5-2** MFA 安装（二维码）/确认、恢复码一次性展示页。
- [ ] **SEC-5-3** 「被新登录挤出」统一跳转提示；会话管理列表页。

### 第 6 步：验证与收口

- [ ] **SEC-6-1** 集成测试：登录并发挤出、TOTP 重放/挑战过期、OAuth/SMS
      绕过、切租户不算新设备、密码变更撤销会话。
- [ ] **SEC-6-2** swagger `@Failure` errCode 注全；ADR-009 状态更新为已落地。

### 独立批次（不与 MFA 捆绑）

- [ ] **SEC-X-1** Bearer JWT 迁出 Web Storage（短期访问令牌 + HttpOnly
      刷新 Cookie 或 BFF）。

## 本批明确不做

- WebAuthn/Passkey（二期抗钓鱼因子）
- 短信作为第二因子（同证据类别不构成 MFA）
