## 1. 状态口径

| 标记 | 含义 |
| --- | --- |
| ✅ 已完成对接 | 页面调用接口并消费真实响应或提交真实请求。 |

| ⛔ 未实现 | 尚无可用页面、路由或业务交互。 |

## 3. 已完成对接的主链路

### 3.1 认证、会话与账号安全

- 登录、注册、找回密码、租户切换和登出均通过认证接口完成。浏览器会话由服务端
  写入 `HttpOnly` Cookie；前端刷新时通过 `/auth/userinfo` 确认会话，JWT 不再存入
  Web Storage。
- TOTP 登录挑战、恢复码、账号安全概览、禁止同时登录、当前账号设备会话列表和撤销
  均已接入。密码等高风险操作使用二次验证令牌，密码修改或会话被挤出会回到登录态。
- 入口主要位于 `pages/auth/`、`stores/auth.ts`、`pages/dashboard/account.vue` 及
  `components/dashboard/account/`。

### 3.2 应用、菜单与收藏

- 应用工作区使用 `GET /apps/code/:code/menu` 的菜单快照构建资产树，按服务端可见性、
  排序和 `menuRevision` 渲染；不再使用项目档案等硬编码预览菜单。
- 可创建分组及普通/流程型表单，支持移动菜单、删除表单、切换表单类型、收藏/取消收藏。
  表单名称与图标通过表单接口保存，服务端同事务同步菜单节点。
- 图标选择器为独立组件，按仪表盘、普通表单、流程表单和分组映射颜色，并同时用于
  选择器预览与左侧菜单展示。
- 相关实现位于 `pages/app/index.vue`、`composables/useAppMenu.ts`、
  `components/app/workspace/`、`api/apps.ts`、`api/form.ts`、`api/menuFavorites.ts`。

### 3.3 表单资产、运行时与数据

- 设计工作区按表单公开编码加载详情和草稿，支持保存、发布、乐观锁冲突处理，以及
  物理存储异步 DDL Job 状态查询。
- 已发布表单在应用内运行时和独立预览页均通过 bootstrap 获取冻结快照，并以幂等键
  提交真实记录；数据页支持 Query DSL 筛选、分页、创建/删除记录和成员信息卡片。
- 表单权限组及字段权限配置已由应用设置页消费真实接口。

### 3.4 流程设计与审批

- `pages/form/workflow.vue` 以流程型表单的 `formCode` 定位或懒建流程定义；支持草稿
  保存、发布、发布校验 issues 定位、版本历史、不可变快照预览和全屏编辑。
- `@evolyn.do/workflow` 提供 LogicFlow 画布、DSL 适配、节点属性编辑和审批人配置；
  流程草稿/版本都通过 `/workflows` 真实持久化，不再使用本地默认文档。
- 应用工作区已接入待办、已办、我发起和抄送导航及任务详情/动作接口。

### 3.5 工作台、消息与租户管理

- 自定义工作台通过 `/workbench` 读取和保存，不再写入浏览器 `localStorage`；菜单收藏
  由 `/menu-favorites` 持久化，并可从工作台和应用工作区打开。最近使用与待办快捷卡
  暂未接入访问/流程数据源。
- 消息中心已读取通知列表和未读摘要，支持已读、全部已读、通知偏好及收件人管理。
- 产品中心、版本、企业资料、组织架构、企业日志与产品日志页面已有实际 API 消费；
  各页面仍以权限和后端能力为最终边界。

## 5. 维护规则

- 新页面、接口替换或移除样例数据时，同步更新总览和对应小节。
- 只有页面实际调用接口并消费真实结果，才可标为“已完成对接”。
- 状态说明必须区分前端未接入、后端未提供与权限不可用，避免把任一情况笼统写成
  “未实现”。
