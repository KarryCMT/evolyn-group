# 消息中心

本目录承载成员端消息中心的现状分析、站内消息、已读状态、租户通知偏好、提醒对象与邮件/短信投递的后端设计。

## 文档导航

- [消息中心现状分析与后端开发设计.md](./消息中心现状分析与后端开发设计.md)：基于 `apps/evolyn-web/apps/web/src/components/dashboard/messageCenter/` 的实际组件和交互盘点，定义领域边界、事件目录、数据模型、API、权限、可靠投递、前端接入与验收方案。

> 本模块是成员端站内消息与通知偏好，不等同于管理后台的外部 Webhook「消息推送」；后者见 `../消息推送/`。
