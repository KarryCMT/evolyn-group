# 菜单按钮权限与节点状态设计方案（ADR-011）

> 状态：已实施（后端批）。迁移 000046/000047；动作注册表
> `iam/authorization/menuactions.go`；表单契约 §2.3/§4 同步更新。

## 1. 背景与目标

应用菜单（`application_menu_entries`）中的表单/仪表盘/分组节点带有右键按钮
集合，需要按「成员角色 × 节点类型」控制按钮的可见与可用。实施前后端仅有两层
授权：URL 级 `resource:verb` RBAC（中间件）与菜单读取时应用级派生的粗粒度
`capabilities`，无按钮粒度。

本方案的目标：

1. 按钮能力（可见性）由服务端读时派生并随菜单快照出网，前端只按投影渲染，
   不自行猜按钮；
2. 每个按钮背后的写接口在 Service 层做动作级复核，动作授权不可能越权放大
   URL 访问；
3. 与既有 RBAC（`roles.rules` JSONB）、权限中心、迁移补授体系同构，不引入
   第二套授权事实源。

## 2. 按钮集合（产品口径，已拍板）

| 动作 | 流程表单 | 普通表单 | 仪表盘 | 分组 |
| --- | --- | --- | --- | --- |
| 编辑 | ✓ | ✓ | ✓ | ✗ |
| 修改名称（表单含图标/颜色） | ✓ | ✓ | ✓ | ✓（仅名称） |
| 切换为普通/流程表单 | ✓ | ✓ | ✗ | ✗ |
| 查看引用视图 | ✓ | ✓ | ✗ | ✗ |
| 复制到当前应用 | ✓ | ✓ | ✗ | ✗ |
| 复制到其他应用 | ✓ | ✓ | ✗ | ✗ |
| 移动 | ✓ | ✓ | ✓ | ✓ |
| 收藏 | ✓ | ✓ | ✓ | ✗ |
| 对成员隐藏 | ✓ | ✓ | ✓ | ✗ |
| 删除 | ✓ | ✓ | ✓ | ✓ |

已拍板的语义：

- **切换类型**：standard↔workflow 可互转（迁移 000044 的「创建后不可变」不再
  成立）；流程表单切标准后原流程数据保留，仅不可再发起流程。
- **复制拆两个动作码**：`copy-in-app`（复制到当前应用）与 `copy-cross-app`
  （复制到其他应用）分别授权；仪表盘资产域落地后其「复制」挂 `copy-in-app`。
- **对成员隐藏**：仅导航隐藏——普通成员菜单读侧裁剪，runtime 直连不受拦截
  （资产级访问控制属后续批次）；菜单管理成员（applications:create/patch）
  仍可见以便恢复。
- **收藏**：个人状态动作，不是授权对象——凡节点可见即可收藏
  （`menu-favorites` 资源授全体成员）。
- **仪表盘**：`entry_type=dashboard` 资产域未落地，动作在注册表以
  `Landed=false` 占位，落地前不投影（与 `MenuFeatures.workflow` 同口径）。
- **分组按钮**：修改名称、移动、删除三项，授权复用 applications 资源。

## 3. 模型

### 3.1 动作注册表（代码常量，唯一事实源）

`iam/authorization/menuactions.go`：节点类型 → 动作授权表。每个
`MenuActionSpec` 声明动作码、授权键列表（**AND 语义**，除 `form-actions:*`
动作键外一并声明 URL 门权限键，保证「按钮不撒谎」——投影出的按钮不会被
中间件 403）与 `Landed`（端点未落地不投影）。派生入口：

```go
MenuActionsOf(perms map[string]bool, assetType string) map[MenuAction]bool
```

授权键映射（表单节点）：

| 动作 | 授权键（全部命中） |
| --- | --- |
| edit | `forms:update` |
| rename | `forms:patch` |
| switch-type | `form-actions:switch-type` + `forms:create` |
| reference-view | `forms:get` |
| copy-in-app | `form-actions:copy-in-app` + `forms:create` |
| copy-cross-app | `form-actions:copy-cross-app` + `forms:create` |
| move | `applications:patch` |
| hide | `form-actions:hide` + `applications:patch` |
| delete | `forms:delete` |

分组节点：rename/move → `applications:patch`，delete → `applications:delete`。

### 3.2 授权存储：扩展 `roles.rules`，不建新表

新增资源常量 `form-actions`（`iam/model/rbac.go`）。动作授权是规则行
`{resource: "form-actions", operation: "switch-type"}`：

- `Operation.Contain` 的精确匹配与 `PermissionsOf` 的键透传天然支持，
  权限派生零改动；
- `form-actions` 不对应任何 URL 首段，中间件 URL 门永不命中——动作授权
  不可能越权放大 URL 访问，真实裁决在各域 Service（与表单契约「服务层复核」
  先例一致）；
- 被否备选：自定义动词（方案文档 §9 已警告不得以 URL Authorizer 不识别的
  动词假实现）；独立授权表（与 `roles.rules` 形成双事实源）。

### 3.3 节点状态：`hidden` 列（000046）

`application_menu_entries.hidden boolean NOT NULL DEFAULT false`。放独立列
而非 `config` JSONB——方案已限定 config 只放小型显示配置，可见性是权限语义。
可见性裁剪：`assetVisible && (!hidden || canManageMenu)`；分组因后代全隐藏被
既有 `hasVisibleDescendant` 链路自然裁剪。

### 3.4 个人状态：`application_menu_favorites`（000046）

`(tenant_id, member_id, application_id, entry_id, created_at)`，
`(member_id, entry_id)` 唯一幂等；硬删除（个人状态无保留价值）。收藏挂菜单
节点（导航位置）而非资产；表单删除事务内经 `MenuMaintenance.DetachFormEntry`
级联硬删关联收藏行。收藏不递增 `menu_revision`——不改变共享菜单结构。

## 4. 能力投影（读时派生，不落库）

菜单快照 `entryMap[].capabilities` 演进：

```jsonc
{
  "view": true,
  "favorite": true,                       // 个人状态能力：凡可见即可收藏
  "actions": {                            // ADR-011：按钮级，按钮唯一事实源
    "edit": true, "rename": true, "switchType": false,
    "referenceView": true, "copyInApp": true, "copyCrossApp": false,
    "move": true, "hide": true, "delete": true
  }
}
```

`MenuEntryDetail.Favorited` 出网当前成员收藏状态。派生因子：动作注册表 ×
权限集 × 节点类型 × 应用可编辑（active 且非初始化中，归档/初始化中全部动作
关闭）。未适配节点类型的动作保持零值 false。

旧契约的 `manage/move/delete` 粗粒度字段已从 capabilities 移除（开发期无
存量客户端，不做兼容双写）：分组「新建资产」入口等原 `manage` 消费方改读
`actions.rename`（同因子 applications:patch × 可编辑）；仪表盘资产域落地
前其 actions 占位恒 false，浮窗仅出收藏个人状态动作，不以粗粒度能力伪造
按钮（与 `MenuFeatures.workflow` 同口径）。

## 5. 接口清单

| 接口 | URL 门 | 动作复核（Service） | 说明 |
| --- | --- | --- | --- |
| PATCH /applications/code/:code/menu/entries/:entryCode | applications:patch | hide 开关另核 `form-actions:hide` | 分组改名（仅分组；资产节点改名 400 `APP_MENU_ENTRY_RENAME_FORBIDDEN`，以资产域为事实源）/ hidden 开关（仅资产节点，分组 400 `APP_MENU_HIDDEN_INVALID`）/ 移动（防自环、两层限制，追加目标末位）；menuRevision 乐观锁 |
| POST /menu-favorites | menu-favorites:create | —（个人状态） | 收藏；重复幂等；应用/节点定位失败 400 `APP_MENU_FAVORITE_INVALID` |
| DELETE /menu-favorites/:entryCode | menu-favorites:delete | — | 取消收藏；幂等 |
| POST /forms/:code/switch-type | forms:create | `form-actions:switch-type` | 类型切换；400 `FORM_TYPE_UNCHANGED` |
| POST /forms/:code/copy | forms:create | `copy-in-app` / `copy-cross-app` | 复制；跨应用另核目标应用 active + 配额 |
| GET /forms/:code/references | forms:get | — | 引用视图（application 域菜单仓储窄端口反查） |
| PATCH /forms/:code | forms:patch | — | 名称 + 图标/颜色（「修改名称和图标」单一权限点，经 `MenuMaintenance.SyncFormEntryAppearance` 同事务同步节点） |

## 6. 基线与存量补授

- 新租户 `seedTenantBaseline`：tenant-admin 追加 `{form-actions, *}`；
  authenticated 追加 `{menu-favorites, create}` + `{menu-favorites, delete}`。
- 存量租户迁移 000047：管理员按「规则签名」（members:\*+roles:\*+departments:\*，
  与角色名无关，口径同 000035/000037/000039）补授 `form-actions:*`；
  authenticated 系统分组关联角色补授 menu-favorites（口径同 000040）。
- 资源目录 `form-actions`/`menu-favorites` 由 `iam/repository.Init()` 幂等种子。
