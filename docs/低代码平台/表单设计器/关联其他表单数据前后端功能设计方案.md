# 关联其他表单数据前后端功能设计方案

## 1. 目标与边界

在表单设计器中，仅 `combo`（下拉框）和 `combocheck`（下拉复选框）的「字段属性 > 选项」提供「关联其他表单数据」。`radiogroup`、`checkboxgroup` 及其他字段不展示、不接受该配置，前后端校验器均拒绝越界 Schema。

本期支持同应用内已发布的普通表单，不暴露物理表或列名。跨应用数据源需要独立的应用访问权限模型，不在本期通过前端参数放开。

## 2. 交互设计

### 2.1 设计器属性面板

- 「选项」的来源选择为「自定义」、「关联其他表单数据」；「数据联动」作为禁用的后续能力提示。
- 自定义模式保留现有选项增删改和默认值。
- 关联模式依次选择表单、字段，选择后显示「表单--字段」摘要；该模式没有默认值，切换时清空旧默认值。
- 可按「当前选项的值」、源表单字段、提交时间或更新时间升/降序。
- 「添加过滤条件」打开大尺寸对话框，支持「所有 / 任一」逻辑、多条条件、当前表单字段值或自定义值。操作符按源字段类型封闭。

### 2.2 可用性状态

- 未选表单时禁用字段和过滤设置；更换源表单时原字段、排序和过滤一并重置。
- 表单/字段列表支持搜索、加载态和失败提示；已发起的请求在重选或组件卸载时取消。
- 运行时首次渲染和获得焦点时查询选项；短暂错误保留已加载选项，避免用户当前值被突然清空。

## 3. 复用设计

- 表单和字段候选复用 `LinkageDesignerAdapter`，宿主应用继续管理认证和 API 地址，`@evolyn.do/form` 不依赖 HTTP 客户端。
- 过滤行复用 `LinkageConditionEditor`、`DataLinkageCondition` 和字段类型兼容矩阵，不创建第二套条件协议。
- 后端复用数据联动的已发布字段目录和操作符矩阵，选项查询复用 `ListRecords` 的参数化 Query DSL、行级范围和字段权限裁剪。

## 4. 协议 v13

`optionSource` 是 `combo` / `combocheck` 的可选属性；旧版缺省即「自定义」，无需写入冗余迁移数据。

```json
{
  "optionSource": {
    "mode": "related",
    "related": {
      "source": {
        "type": "form",
        "appId": 7,
        "sourceId": "form_product",
        "fieldId": "_widget_product_name"
      },
      "sort": { "fieldId": "sys.updatedAt", "direction": "desc" },
      "filter": {
        "logic": "and",
        "conditions": [
          {
            "id": "cond_xxx",
            "sourceFieldId": "_widget_status",
            "operator": "eq",
            "value": { "type": "constant", "value": "启用" }
          }
        ]
      }
    }
  }
}
```

关联值字段限文本、数字、日期时间、单/多选、下拉单/多选和流水号。多值字段展平为多个选项，最终按字符串值去重。

## 5. 接口

### 5.1 设计期元数据

`GET /api/v1/forms/:sourceCode/linkage-fields`

复用现有接口，返回已发布逻辑字段、类型和允许操作符，并按设计者对源表单的字段权限裁剪。

### 5.2 运行时选项查询

`POST /api/v1/forms/:formCode/option-fields/:fieldId/query`

```json
{
  "schemaVersion": 3,
  "values": { "_widget_category": "设备" },
  "keyword": "A",
  "pageSize": 100
}
```

返回 `{ "items": [{ "label": "A01", "value": "A01" }], "total": 1 }`。浏览器不得传源表、源字段、排序字段或操作符；服务端必须从目标表单的当前不可变发布快照取出可信配置。版本号不一致返回 `FORM_OPTION_SOURCE_VERSION_CONFLICT`。

## 6. 服务端安全与上限

- 发布终审校验同应用归属、源表发布状态、字段类型、操作符和当前表单依赖字段的类型兼容性。
- 运行查询映射为 `form-records:get`，并继续经过源表的 `FormPermissionEvaluator`；无权字段不参与选项输出。
- Query DSL 始终参数化；单次最多读取 1000 条有权记录，最多返回 100 个去重选项。
- 空的当前表单依赖值直接返回空选项，不放宽过滤条件。

## 7. 验收清单

- 下拉框、下拉复选框可切换来源、选源字段、排序和过滤；其他字段无入口且伪造 Schema 被拒绝。
- 过滤条件的当前字段被重命名时引用同步重写；被删除或变更为不兼容类型时设计器阻止操作。
- 不同权限组成员看到的选项只来自其有权记录和可见字段。
- 旧表单读取后保持自定义选项语义；发布 v13 快照后 Web/移动端运行时可加载关联选项。
