## 关键约定（勿推翻）

- 业务包禁止 import decimal.js / shopspring- decimal 直用；统一走
  `@evolyn.do/numeric`（前端）与 `internal/platform/numeric`（Go）。
- 技术控制数值（page/index/count）→ number；业务十进制 → decimal string（§27）。
- 跨端语义改动必须先改 `docs/contracts/numeric-test-vectors.json` 再动两端实现。
- 运行链（Phase 3 起）：formula-runtime 求值 → numeric 执行；
  文本/日期公式函数不在数值运行时范围。
