# 目标保存协议字段字典（P0 协议冻结交付物）

本文件是《目标保存协议重构与分期实施方案.md》P0 阶段的首个交付物：对 27 种 `widget.type`
逐项冻结属性结构、类型、默认值、`null` 语义、值协议、前端展示、后端校验与测试要求。
P1 起前端类型/校验器、后端校验器、发布白名单与运行时组件必须与本字典一致；每项协议修改
需同步修订本文件并走 ADR（第 27 章）。

## 1. 协议总则

### 1.1 根结构（唯一事实结构，禁止中间等价 Schema）

```json
{
  "content": {
    "type": "form",
    "layout": "normal",
    "items": [ /* 顶层字段定义池，见 §2 */ ],
    "layout_fields": [],
    "field_layout": []
  }
}
```

- 根对象只允许 `content` 一个键；v4 `content` 只允许 `type`、`layout`、`items`、
  `layout_fields`、`field_layout` 五个键。
- `content.type` 固定为 `form`，其他值一律非法。
- `content.items` 是顶层字段定义的唯一事实源；条目上限 500
  （`subform.items` 上限 200），超限拒绝保存。
- **未知键拒绝**：任何层级的未知键不静默删除，保存与发布均返回 JSON Path 级错误
  （如 `content.items[2].widget.unknown`）。版本升级策略明确后，新增属性必须以新协议
  版本与迁移器演进（见 1.3）。

### 1.2 缺省值、null 与布尔语义（逐项定义，禁止 truthy/falsy 判断）

| 属性类别 | 缺省（键不存在） | 显式 `null` | 说明 |
| --- | --- | --- | --- |
| 布尔属性（`enable`/`visible`/`allowBlank`/`labelHidden` 等） | 必填键，无缺省语义 | 非法 | 校验器要求键必须存在且为布尔值；设计器创建时写入字典默认值 |
| 枚举属性（`format`/`layout`/`style` 等） | 取字典标注的默认枚举值 | 非法 | 枚举值集合封闭，未列出的值非法 |
| 数值约束（`minLength`/`maxCount` 等） | 未启用该约束 | 等价于未启用 | 两态一致；约束启用时必须满足字典标注的取值范围 |
| 字符串属性（`placeholder`/`description` 等） | 等价于 `""` | 非法 | 文本类属性不允许 `null`，空串即「无」 |
| 数组属性（`options` 等） | 必填键（选项类控件）或空数组 | 非法 | 选项数组最小长度见各控件条目 |

### 1.3 协议版本策略

- 文档内**不携带**版本号字段；当前版本为 v4。
- 协议版本由持久层外部承载：`forms.protocol_version`、`form_versions.protocol_version`
  列 + 代码常量 `FORM_PROTOCOL_VERSION = 4`。
- 版本迁移器只做「读入旧文档 → 迁移为当前版本 → 校验」三步；
  v1 平铺文档读取时迁移为 `layout_fields=[]`，并按 `items` 顺序生成
  `field_layout`；v1/v2 读取时统一补 `layout=normal`；v1–v3 子表单读取时补齐 v4
  的行权限、冻结列与移动端展示默认值。未来新增属性继续递增版本号，
  禁止在既有版本内隐式兼容。

### 1.4 表单默认列布局

- `content.layout` 为必填枚举：`normal`、`grid-2`、`grid-3`、`grid-4`。
- 切换布局时，设计器同步把所有普通顶层字段（含标签页引用字段）的 `lineWidth`
  重置为 `12`、`6`、`4`、`3`；分割线等布局字段保持 `12`。
- 子表单作为横向明细容器固定占整行，`lineWidth` 必须为 `12`，不随多列布局变化。
- 字段仍可在布局重置后单独覆盖宽度；新增字段继承当前布局对应的默认宽度。
- 字段宽度指令固定为：`1/4=3`、`1/3=4`、`1/2=6`、`2/3=6`、
  `3/4=9`、`整行=12`。

### 1.5 `widgetName` 规则

- 非空字符串，长度 1–64，形如标识符：`^[A-Za-z_][A-Za-z0-9_]*$`。
- 设计器生成约定：`_widget_` 前缀 + 时间戳/随机串（如 `_widget_1724726400000`）。
- 唯一性作用域：顶层 `items` 内全表单唯一；`subform` 的嵌套 `items` 在该子表单
  作用域内唯一（子作用域键不与顶层键冲突，因为子表单值按行嵌套存储）。

### 1.6 执行阶段登记口径

| 登记 | 含义 |
| --- | --- |
| 首期执行 | P1/P2 即实现：设计器可编辑、保存/发布可校验、运行时可渲染/校验/提交 |
| 保存但延后执行 | P1 起可保存（结构校验生效），运行行为按标注阶段落地；未落地前该控件被发布白名单拦截 |
| 不纳入目标协议 | 旧 `FormDocument` 侧概念，明确迁移去向，不得继续写入新协议 |

### 1.7 v2 标签页布局引用

- `layout_fields` 是表单级布局定义池，首期只允许 `multitab`，最多 50 个布局。
- `field_layout` 是顶层唯一排列序列，可引用顶层 `widgetName` 或布局 `name`。
- `multitab.container` 为 1–20 个 `tab`；每个 `tab.field_layout` 只引用
  `content.items` 中的顶层字段，允许引用 `subform`，但禁止引用子表单内部字段。
- 每个顶层字段和布局必须恰好被引用一次；重复、悬空和孤儿引用均拒绝保存。
- 首期禁止布局嵌套。删除标签页或标签页组时只解散引用，不删除字段定义。

## 2. 字段项（item）公共属性

```json
{
  "widget": { "type": "text", "widgetName": "_widget_x", "enable": true, "visible": true, "allowBlank": true },
  "description": "",
  "label": "单行文本",
  "labelHidden": false,
  "lineWidth": 12
}
```

| 属性 | 类型 | 必填 | 默认/约束 | 语义 | 执行阶段 |
| --- | --- | --- | --- | --- | --- |
| `widget` | object | 是 | — | 控件判别与专属配置，见 §3 | P1 |
| `label` | string | 是 | 除 `separator` 允许空串外，其余 trim 后 1–64 字符 | 字段显示名称 | P1 |
| `description` | string | 是 | 0–500 字符 | 字段说明文案 | P1（保存）/P2（运行时展示） |
| `labelHidden` | boolean | 是 | 默认 `false` | 隐藏标签（仍渲染控件与说明） | P2 |
| `lineWidth` | integer | 是 | 1–12，默认 12；子表单固定为 12；其他普通字段开放 3/4/6/6/9/12 六条宽度指令 | 桌面 12 栅格占列数；移动端恒单列 | P2 |

`widget` 层公共属性（所有 27 种控件一致）：

| 属性 | 类型 | 必填 | 默认 | 语义 | 执行阶段 |
| --- | --- | --- | --- | --- | --- |
| `type` | string | 是 | — | 控件判别键，27 值枚举 | P1 |
| `widgetName` | string | 是 | — | 稳定字段键（记录值/规则/错误回填键），规则见 1.5 | P1 |
| `enable` | boolean | 是 | `true` | `false` 时禁用输入，值仍参与提交 | P2 |
| `visible` | boolean | 是 | `true` | `false` 时不渲染、不校验、不收集值 | P2 |
| `allowBlank` | boolean | 是 | `true` | `false` 时必填（空值校验前后端一致执行） | P1 |

无值控件（`separator`、`button`）同样携带全部公共属性；其 `allowBlank`、`enable`
为结构占位（校验布尔合法性），运行时忽略，不产生值语义。

## 3. 控件字典（27 种）

约定：每条目给出「专属属性表 + 值协议 + 执行阶段」。未在专属属性表出现的键即非法。
选项结构统一为 `{ "label": string, "value": string }`（label 1–100、value 1–100、组内
value 唯一、1–200 项）。

### 3.1 基础输入与选项（P2 全量执行）

#### text 单行文本

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `placeholder` | string | 否 | `""`，≤100 字符 |
| `minLength` | integer | 否 | 未启用 / 0–1000 |
| `maxLength` | integer | 否 | 未启用 / 1–1000；与 `minLength` 同时启用时 `min ≤ max` |
| `format` | string 枚举 | 否 | `""`（不限）/ `email` |
| `defaultValue` | string | 否 | 未启用 / ≤1000 字符（**保存但延后执行**：P5 规则引擎统一落地默认值） |

值协议：`string | null`；空值 `null`。`allowBlank=false` 时 trim 后非空；启用长度时按
字符串长度校验；`format=email` 时按 RFC 5322 简化规则校验。

#### textarea 多行文本

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `placeholder` | string | 否 | `""`，≤100 |
| `minLength` | integer | 否 | 未启用 / 0–2000 |
| `maxLength` | integer | 否 | 未启用 / 1–2000；`min ≤ max` |
| `autoHeight` | boolean | 否 | 默认 `false`（固定高度，true 随内容增高） |
| `defaultValue` | string | 否 | 未启用 / ≤2000（延后执行同 text） |

值协议：`string | null`，同 `text`（无 `format`）。

#### number 数字

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `placeholder` | string | 否 | `""`，≤100 |
| `min` | number | 否 | 未启用；启用时有限数值 |
| `max` | number | 否 | 未启用；启用时有限数值且 `min ≤ max` |
| `precision` | integer | 否 | 未启用 / 0–8（小数位数） |
| `defaultValue` | number | 否 | 未启用（延后执行同 text；启用时须满足 min/max/precision） |

值协议：`number | null`（有限数值）；`precision` 启用时按四舍五入归一。

#### datetime 日期时间

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `format` | string 枚举 | 否 | 默认 `datetime`；`date` / `datetime` / `month` / `time` |
| `placeholder` | string | 否 | `""`，≤100 |
| `defaultValue` | string | 否 | 未启用；形状须符合所选 `format`（延后执行同 text） |

值协议：`string | null`，按 `format` 的规范形状：`date`→`YYYY-MM-DD`、
`datetime`→`YYYY-MM-DD HH:mm:ss`、`month`→`YYYY-MM`、`time`→`HH:mm`；非法日期
（如 2026-02-30）拒绝。

#### radiogroup 单选组

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `options` | 选项数组 | 是 | 1–200 项，组内 `value` 唯一 |
| `layout` | string 枚举 | 否 | 默认 `vertical`；`vertical` / `horizontal` |
| `defaultValue` | string | 否 | 未启用；须为选项 `value` 之一（延后执行同 text） |

值协议：`string | null`，非空时必须命中选项 `value`；`allowBlank=false` 时必选。

#### checkboxgroup 复选组

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `options` | 选项数组 | 是 | 1–200 项 |
| `layout` | string 枚举 | 否 | 默认 `vertical` |
| `defaultValue` | string[] | 否 | 未启用 / 空数组；每项须为选项 `value`（延后执行同 text） |

值协议：`string[]`（空数组=未选）；`allowBlank=false` 时至少一项；元素必须命中选项
`value` 且不得重复。

#### combo 下拉单选

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `options` | 选项数组 | 是 | 1–200 项 |
| `placeholder` | string | 否 | `""`，≤100 |
| `filterable` | boolean | 否 | 默认 `false`（可搜索） |
| `defaultValue` | string | 否 | 未启用；须为选项 `value` 之一（延后执行同 text） |

值协议：`string | null`，同 `radiogroup`。

#### combocheck 下拉多选

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `options` | 选项数组 | 是 | 1–200 项 |
| `placeholder` | string | 否 | `""`，≤100 |
| `defaultValue` | string[] | 否 | 未启用 / 空数组（延后执行同 text） |

值协议：`string[]`，同 `checkboxgroup`。

#### separator 分割线（布局项，无值）

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `style` | string 枚举 | 否 | 默认 `solid`；`solid` / `dashed` |

值协议：无值；不进入值表、不参与校验与提交；`label` 作为分割线文案（允许空串），
运行时整行渲染（忽略 `lineWidth`，占满 12 列）。

### 3.2 组织与文件（结构 P1 冻结，运行能力 P3 落地，此前发布白名单拦截）

#### user 成员单选

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `scope` | string 枚举 | 否 | 默认 `tenant`；`tenant` / `department` |
| `departments` | string[] | 否 | 空数组；`scope=department` 时必须非空（部门 ID 白名单） |
| `defaultValue` | string | 否 | 未启用（延后执行：P5） |

值协议：`string | null`（租户成员 ID）；P3 起服务端复核成员有效性与可见范围。

#### usergroup 成员多选

同 `user` 属性。值协议：`string[]`（成员 ID，不重复）。

#### dept 部门单选

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `includeChildren` | boolean | 否 | 默认 `true`（可选含子部门） |
| `defaultValue` | string | 否 | 未启用（延后执行：P5） |

值协议：`string | null`（部门 ID）；P3 起服务端复核部门归属本租户。

#### deptgroup 部门多选

同 `dept` 属性。值协议：`string[]`（部门 ID，不重复）。

#### image 图片

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `maxCount` | integer | 否 | 默认 9；1–20 |
| `maxSizeMB` | integer | 否 | 默认 10；1–50 |
| `accept` | string[] | 否 | 空数组=默认 `image/*`；MIME 前缀白名单 |

值协议：`FileValue[]`（`{ id, name, size, mimeType, url? }`，服务端文件 ID）；空数组=未传；
提交前必须完成上传；P3 起服务端复核文件归属、数量、类型与大小。

#### upload 附件

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `maxCount` | integer | 否 | 默认 5；1–20 |
| `maxSizeMB` | integer | 否 | 默认 50；1–100 |
| `accept` | string[] | 否 | 空数组=不限；MIME 或扩展名白名单 |

值协议：`FileValue[]`，同 `image`。

#### address 地址

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `level` | string 枚举 | 否 | 默认 `district`；`province` / `city` / `district` / `detail` |
| `detailPlaceholder` | string | 否 | `""`，≤100 |

值协议：`{ province: string; city: string; district: string; detail: string } | null`；
按 `level` 校验层级字段非空（`district` 级要求 province/city/district 非空，`detail`
级再要求 detail 非空）。行政区划数据源 P3 接入。

#### location 定位

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `radius` | number | 否 | 未启用；启用时 10–5000（米，越界提示） |

值协议：`{ latitude: number; longitude: number; label: string } | null`；经纬度为有限
数值（纬度 -90–90、经度 -180–180）；`radius` 仅作前端提示，不做围栏硬校验（P3 复核）。

#### signature 签名

无专属属性。值协议：`string | null`（签名图片的文件 ID）；P3 起与 `image` 同口径复核。

#### phone 手机号

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `areaCode` | string | 否 | 默认 `+86`；形如 `+` 后 1–4 位数字 |
| `verification` | boolean | 否 | 默认 `false`（提交时需短信验证，P3 执行） |

值协议：`string | null`（E.164 本地号；`+86` 区域为 11 位 `1` 开头号码）；P3 起
`verification=true` 时服务端复核验证码凭证。

### 3.3 业务与关联（结构 P1 冻结，运行能力 P4 落地）

#### subform 子表单

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `items` | 字段项数组 | 是 | 协议与顶层 `content.items` 相同；子项 `widgetName` 作用域内唯一；除 `separator`/`richtext`/`subform` 外均可进入，运行能力仍受阶段发布白名单约束 |
| `subformCreate` | boolean | 是 | `true`；允许在尾部新增记录 |
| `subformInsert` | boolean | 是 | `true`；允许在指定行前后插入记录 |
| `subformEdit` | boolean | 是 | `true`；允许修改已有记录 |
| `subformDelete` | boolean | 是 | `true`；允许删除已有记录 |
| `quickFill` | boolean | 是 | `true`；仅在新增与编辑已有记录同时允许时生效 |
| `pcStickyColumn` | `{enable,limit}` | 是 | `{true,1}`；`limit` 为 1–5 |
| `mobileStickyColumn` | `{enable,limit}` | 是 | `{false,1}`；横向表格模式生效，`limit` 为 1–5 |
| `mobileViewStyle` | enum | 是 | `vertical`；`vertical/horizontal` |
| `mobileSummaryFieldCount` | integer | 是 | `3`；纵向卡片收起时展示前 1–5 个字段值 |
| `minRowCount` | integer | 否 | 未启用 / 0–200 |
| `maxRowCount` | integer | 否 | 未启用 / 1–200；`min ≤ max` |

值协议：行数组 `Record<子 widgetName, 子值>[]`；行内校验逐行执行；行 ID（`_rowId`）
由运行时生成、不进入提交值（P4 以服务端行级校验复核）。

设计态允许从素材面板拖入或从属性面板添加子字段，并支持排序、复制、删除与单独配置。
标签页不属于字段类型；`separator`、`richtext`、`subform` 不得进入子表单，避免布局与递归
结构混入行数据。桌面设计预览采用横向表格，移动端运行态按 `mobileViewStyle` 投影。

#### linkquery 关联查询

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `targetForm` | string | 否 | 未启用；发布校验（P4）强制为同租户已发布表单 ID |
| `multiple` | boolean | 否 | 默认 `false`（单选） |
| `filters` | 条件数组 | 否 | 空数组；`{ field, op, value }`，`op` 枚举 `eq/ne/gt/lt/ge/le/contains` |
| `sorts` | 排序数组 | 否 | 空数组；`{ field, order }`，`order` 为 `asc/desc`，≤3 项 |

值协议：`multiple=false` → `string | null`（关联记录 ID）；`multiple=true` → `string[]`。
P4 起服务端按目标表单权限过滤，越权记录不可见。

#### linkfield 关联字段

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `targetForm` | string | 否 | 同 `linkquery` |
| `displayFields` | string[] | 否 | 空数组；目标表单字段键白名单（P4 校验存在性） |

值协议：`string | null`（所引用记录 ID）；展示值由运行时按 `displayFields` 拉取。

#### lookup 数据联动（引用回填）

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `targetForm` | string | 否 | 同 `linkquery` |
| `mappings` | 映射数组 | 否 | 空数组；`{ source: string, target: string }`（目标表单字段键 → 本表单 widgetName） |

值协议：`string | null`（触发记录 ID）；回填行为 P4 落地，服务端复核映射目标存在且
目标字段可写。

#### aggregation 聚合计算

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `expression` | object | 否 | 未启用；受控声明式 `{ op, source, field? }`，`op` 枚举 `sum/avg/count/min/max`，`source` 为本表单 `subform`/`linkquery` 的 `widgetName`，`field` 为源内数值字段键（`op=count` 时省略） |
| `precision` | integer | 否 | 未启用 / 0–8 |
| `displayMode` | string 枚举 | 否 | 默认 `plain`；`plain` / `percent` |

值协议：`number | null`；**只读**（`enable` 恒按禁用执行），关键结果由服务端按
`expression` 重新计算，客户端值仅作展示（P4）。

#### sn 流水号

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `rule.prefix` | string | 否 | `""`，≤32 |
| `rule.dateFmt` | string 枚举 | 否 | 默认 `none`；`none` / `yyyyMM` / `yyyyMMdd` |
| `rule.seqLength` | integer | 否 | 默认 4；3–8 |
| `rule.resetCycle` | string 枚举 | 否 | 默认 `none`；`none` / `daily` / `monthly` / `yearly` |

值协议：`string | null`；**只读**，由服务端在记录受理时按规则生成（并发唯一性由
唯一约束保证，P4）。

### 3.4 富交互（结构 P1 冻结，运行能力 P5 落地）

#### richtext 富文本

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `toolbar` | string[] | 否 | 空数组=默认工具集；工具键白名单 P5 评审 |

值协议：`string | null`（受限 HTML 子集）；P5 建立安全内容模型（标签/属性白名单、
XSS 消毒、编辑/展示隔离）。

#### button 按钮（无值）

| 属性 | 类型 | 必填 | 默认/约束 |
| --- | --- | --- | --- |
| `text` | string | 否 | `""`，≤32 |
| `action.type` | string 枚举 | 否 | 默认 `none`；P5 首批 `none` / `submit`，其余动作键随声明式 actions 评审追加 |

值协议：无值；不进入值表。P5 起以声明式 `actions` 执行模型落地（权限校验、幂等）。

## 4. 值协议总表（提交载荷 `values` 按 `widgetName` 取键）

| 控件 | 值形态 | 空值 | P2 服务端校验 |
| --- | --- | --- | --- |
| text / textarea | `string` | `null` | 长度、format |
| number | `number` | `null` | min/max/precision |
| datetime | `string` | `null` | 按 format 形状与真实日期 |
| radiogroup / combo | `string` | `null` | 命中选项 value |
| checkboxgroup / combocheck | `string[]` | `[]` | 命中、不重复、至少一项（allowBlank=false） |
| separator / button | —（不收集） | — | 出现即拒绝 |
| 其余 18 类 | 见各条目 | — | 随 P3/P4/P5 白名单开放后启用 |

- `visible=false` 的字段不收集：提交载荷不得携带其键（携带非 `null` 值即拒绝）。
- `enable=false` 的字段值仍收集（禁用≠隐藏）。
- 提交载荷出现未定义键（不在快照 `items` 中）一律拒绝并回填该键错误。
- 所有值的 JSON 类型必须与值形态一致（禁止以字符串传数字等隐式转换）。

## 5. 旧 `FormDocument` 概念迁移登记（不纳入目标协议）

| 旧概念 | 处置 |
| --- | --- |
| `FormDocument.version/kind/title/settings` | 不纳入：表单名称/描述落在表单资产行（`forms.name`）；流程形态由工作流域承载，协议不区分；`settings.submitText` 等表单级设置待 P5 以独立声明式配置评审后另行定义，当前不得写入 `content` |
| `FormField.id` | 不纳入：设计器瞬态选择键，不再持久化；`widgetName` 是唯一稳定键 |
| `FormField.required` | 不纳入：以 `widget.allowBlank` 反向表达 |
| `FormField.config` 容器 | 不纳入：专属属性直接平铺在 `widget` 上 |
| 旧 31 类 `FormFieldType` 枚举 | 不纳入：以 27 种 `widget.type` 替换；旧值不迁移（开发环境无存量持久化数据，见迁移清单文档） |

## 6. 发布白名单（能力分批开放）

- P2 白名单（9 类）：`text`、`textarea`、`number`、`datetime`、`radiogroup`、
  `checkboxgroup`、`combo`、`combocheck`、`separator`。
- P3 追加：`user`、`usergroup`、`dept`、`deptgroup`、`image`、`upload`、`address`、
  `location`、`signature`、`phone`。
- P4 追加：`subform`、`linkquery`、`linkfield`、`lookup`、`aggregation`、`sn`。
- P5 追加：`richtext`、`button`（全量 27 类开放）。
- 白名单在前后端各维护一份（`PUBLISHABLE_WIDGET_TYPES`），阶段推进时同批更新；
  发布请求命中白名单外控件时返回精确 JSON Path 错误（`FORM_PUBLISH_UNSUPPORTED_FIELD`）。

## 7. 字段级测试用例要求（每控件最少集）

1. 合法样本原样加载 → 保存后逐字节等价（无损往返）。
2. 每个专属属性各一条非法值用例（类型错误/越界/非法枚举/null 误用）及对应 JSON Path。
3. 未知键拒绝用例（item 层、widget 层、嵌套 `subform.items` 层各一）。
4. `widgetName` 冲突用例（顶层重复、子表单作用域重复、非法字符）。
5. 值协议用例（合法值、空值 + `allowBlank` 两态、类型不符、选项外值）——运行阶段落地
  后的前后端一致校验对拍。
