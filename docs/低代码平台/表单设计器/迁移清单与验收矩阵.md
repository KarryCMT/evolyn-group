# 迁移清单与验收矩阵（P0 协议冻结交付物）

## 1. `FormDocument` 持久化调用点审计与迁移清单

P1 起目标保存协议 `content.items` 是唯一事实结构，旧 `FormDocument {version,kind,title,
fields,settings}` 全链路退场。审计结论（2026-08，现状代码）：**旧协议从未进入任何后端
持久化**，仅存在于前端内存与会话存储，因此无需数据迁移脚本，采用「开发环境无存量数据
切换」方案，直接删除旧路径（git 历史可溯）。

| 调用点 | 现状 | P1 处置 |
| --- | --- | --- |
| `packages/form/src/schema/types.ts`（FormDocument/FormField/31 类枚举） | 旧协议类型源 | 重写为目标协议类型（判别联合）；旧类型删除 |
| `packages/form/src/schema/lifecycle.ts`（migrate/validate/normalize/clone FormDocument） | 旧校验器 | 由 `validate.ts / migrate.ts / clone.ts` 按字段字典替换，错误升级为 JSON Path 级 |
| `packages/form/src/schema/fields.ts`（31 类预设） | 旧字段预设 | 由字典驱动的素材预设替换（P2 仅暴露 9 类基础字段） |
| `packages/form/src/designer/to-form-document.ts`（画布→FormDocument 转换器） | 「画布模型转换另一份发布 Schema」的持久化路径 | **删除**；设计器状态直接为目标协议文档 |
| `apps/web/src/pages/form/design.vue`（画布状态 FormDesignField[]，保存未接后端） | 内存态，刷新即丢 | 切换为协议文档状态 + GET/PUT 草稿接口 |
| `apps/web/src/pages/form/preview-storage.ts` + `preview.vue`（sessionStorage 传 FormDocument、假提交） | 会话存储 + 本地假闭环 | 传目标协议文档；已发布时走 bootstrap + 真实提交 |
| `packages/form/src/runtime/*`（9 类组件按旧 type 注册、按 field.key 取值） | 运行时消费 FormDocument | P2 重写为按 `widget.type` 注册、按 `widgetName` 取值，enable/visible/labelHidden/lineWidth 执行 |
| `packages/form/src/composables/useFormEditor.ts / useFormPersistence.ts` | FormDocument 编辑/持久化 composable，主应用未使用 | 删除（新编辑器状态由 `useFormSchemaEditor` 承担） |
| `packages/form/src/{types.ts,api/,components/{FormDesignCanvas,PluginDesignPanel,FormCodeEditor,FormDesignCodeView,FormSubform*,form-subform-renderer},hooks/useFormDesign*,utils/{designField,widgetName,…}}` | 旧插件设计器遗留簇（主应用零引用） | 删除；P4 子表单设计器按目标协议重建 |
| `packages/form/package.json` 依赖 `monaco-editor` | 仅 FormCodeEditor 使用 | 移除依赖（lockfile 同步） |
| 后端 | 无任何 FormDocument/表单资产代码 | P1 新建 `internal/platform/form` 域（见后端契约文档） |

处置纪律：旧协议**不得**作为兼容层或双写事实来源保留；如未来需要导入历史数据，另行
评审一次性导入器（仅在确有灵衍云存量数据时）。

## 4. 性能基线（P6 压测回归入口值）

- 运行时首屏（runtime 入口 gzip CSS+JS）≤ 40KB，重型字段不得进入基础包（P3 起以
  loader 动态注册验证）。
- bootstrap 单请求返回全部渲染所需数据（快照 + 版本口令），禁止分片拉取。
- 100 字段表单：bootstrap 渲染 ≤ 1s（中端桌面）；输入单字段仅重渲染该字段。
- 提交接口 P95 ≤ 300ms（50 字段内，本地库）；字段错误回填一次往返。
- 长表单/长子表单分页与虚拟列表基线随 P4 压测补录。
