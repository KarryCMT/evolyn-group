## ADDED Requirements

### Requirement: 版本化仪表盘数据协议
系统 SHALL 以版本化领域文档描述数据集、组件、布局、字段编码和展示配置，并 MUST 拒绝未知版本、未知组件和不可序列化配置。

#### Scenario: 保存受支持的统计图和明细表
- **GIVEN** 文档使用当前协议版本且所有标识唯一
- **WHEN** 文档包含合法的统计图、明细表、数据集和布局
- **THEN** 系统接受并规范化该文档

#### Scenario: 拒绝第三方运行时配置作为事实源
- **GIVEN** 文档直接携带未受控的原生图表实例、函数或任意 SQL
- **WHEN** 设计者保存或发布
- **THEN** 系统拒绝该文档并返回路径级协议问题

### Requirement: 数据源与字段目录
系统 MUST 只允许设计者选择当前租户内可访问且已经发布的表单及其稳定字段，并 SHALL 返回与字段类型匹配的筛选、分组、排序和聚合能力。

#### Scenario: 读取同租户可访问字段
- **GIVEN** 设计者对目标表单拥有查看权限且表单存在发布快照
- **WHEN** 设计器加载该表单的仪表盘字段目录
- **THEN** 系统返回稳定字段标识、展示名称、值类型和受支持能力

#### Scenario: 跨租户或无权限数据源不可见
- **GIVEN** 目标表单属于其他租户或设计者没有查看权限
- **WHEN** 设计器搜索或直接请求该表单字段目录
- **THEN** 系统不返回该数据源或字段元数据

### Requirement: Dataset 与组件绑定
系统 SHALL 允许一个仪表盘定义多个 Dataset，并 SHALL 允许组件通过稳定 Dataset 标识及字段编码绑定数据；被引用的 Dataset 或字段失效时发布 MUST 被阻止。

#### Scenario: 统计图绑定维度和指标
- **GIVEN** Dataset 的维度字段可分组且指标字段支持所选聚合函数
- **WHEN** 设计者把统计图绑定到该 Dataset
- **THEN** 设计器生成可验证的维度、指标和展示编码

#### Scenario: 明细表绑定列与分页
- **GIVEN** Dataset 包含当前成员可查看的字段
- **WHEN** 设计者配置明细表列、排序和分页大小
- **THEN** 系统保存稳定字段标识和受控排序配置

#### Scenario: 引用失效字段时阻止发布
- **GIVEN** 草稿引用的表单字段在当前发布快照中已不存在或能力不再匹配
- **WHEN** 设计者发布仪表盘
- **THEN** 系统返回指向 Dataset 和组件绑定的结构化问题
- **AND** 不生成新的仪表盘发布版本

### Requirement: 服务端权威查询
仪表盘查询 MUST 由服务端根据已保存草稿或不可变发布快照恢复可信 Dataset 配置并执行；客户端不得通过请求扩大数据源、字段、操作符、聚合或数据范围。

#### Scenario: 设计态查询使用已保存草稿
- **GIVEN** 设计者已保存包含合法 Dataset 的草稿
- **WHEN** 设计器按组件标识请求预览数据
- **THEN** 系统使用指定草稿修订中的 Dataset 配置执行查询
- **AND** 仅接受受控筛选值、分页和组件标识作为运行参数

#### Scenario: 运行态查询使用发布快照
- **GIVEN** 成员正在查看已发布仪表盘
- **WHEN** 运行时按组件标识请求数据
- **THEN** 系统使用运行时 bootstrap 指定的不可变发布版本执行查询
- **AND** 后续未发布草稿修改不影响结果语义

#### Scenario: 客户端尝试扩大查询
- **GIVEN** 客户端在请求中伪造额外字段、数据源、聚合或原始查询表达式
- **WHEN** 服务端处理查询
- **THEN** 系统忽略或拒绝非协议运行参数
- **AND** 查询范围不超过已保存配置和当前成员权限的交集

### Requirement: 数据权限与范围裁剪
每次仪表盘查询 MUST 重新校验当前成员身份、表单入口权限、字段权限和行级数据范围，并 MUST 对设计者与普通查看者分别应用各自的有效权限。

#### Scenario: 普通成员只看到有权数据
- **GIVEN** 仪表盘 Dataset 指向包含多成员数据的表单
- **WHEN** 一个仅有本人数据范围的成员查看统计图或明细表
- **THEN** 聚合值、明细行和可见字段均只基于该成员有效数据范围

#### Scenario: 权限在发布后被收紧
- **GIVEN** 仪表盘发布后成员的表单权限被收紧
- **WHEN** 该成员再次查询组件数据
- **THEN** 系统立即按新的权限裁剪或拒绝查询
- **AND** 不因仪表盘发布快照保留旧权限

### Requirement: 查询结果契约与资源限制
系统 SHALL 为统计图返回稳定的维度/指标结果，为明细表返回稳定分页结果，并 MUST 对查询复杂度、返回行数、执行时间和并发量执行服务端上限。

#### Scenario: 数值结果保持精度
- **GIVEN** 指标聚合高精度小数、金额或百分比字段
- **WHEN** 查询成功
- **THEN** 结果以规范化十进制字符串返回且不发生 JavaScript 浮点精度损失

#### Scenario: 明细表稳定分页
- **GIVEN** 多条记录的用户排序值相同
- **WHEN** 成员连续请求明细表分页
- **THEN** 系统追加稳定尾排序并保证记录不重复、不遗漏

#### Scenario: 查询超过服务端限制
- **GIVEN** Dataset 产生超过允许复杂度、耗时或返回规模的查询
- **WHEN** 服务端执行或预检查询
- **THEN** 系统终止请求并返回稳定的查询限制错误
- **AND** 记录可观测的失败原因而不返回部分越权数据
