## ADDED Requirements

### Requirement: 仪表盘发布终审
系统 SHALL 只允许有发布权限的成员基于当前草稿修订发布仪表盘，并 MUST 在创建版本前终审文档结构、数据绑定、发布范围和所有引用资产。

#### Scenario: 发布有效草稿
- **GIVEN** 当前草稿已保存、修订号最新且全部引用有效
- **WHEN** 有权限成员提交发布
- **THEN** 系统创建新的不可变发布版本并返回递增的发布版本号

#### Scenario: 使用过期修订发布
- **GIVEN** 草稿在发布请求形成后又被保存过
- **WHEN** 成员使用旧草稿修订号发布
- **THEN** 系统返回稳定的发布冲突错误
- **AND** 不创建发布版本

#### Scenario: 发布校验失败
- **GIVEN** 草稿包含无效 Dataset、组件绑定、筛选、联动或发布范围
- **WHEN** 成员提交发布
- **THEN** 系统返回可定位到文档路径的完整问题清单
- **AND** 当前线上版本保持不变

### Requirement: 不可变发布版本
系统 MUST 保留每次成功发布的不可变文档快照，历史版本不得被后续草稿保存、改名或再次发布修改。

#### Scenario: 发布后继续编辑草稿
- **GIVEN** 仪表盘已经发布版本 1
- **WHEN** 设计者修改并保存新草稿但尚未再次发布
- **THEN** 运行时继续使用版本 1
- **AND** 预览可以使用新的草稿修订

#### Scenario: 再次发布
- **GIVEN** 版本 1 已发布且新草稿通过终审
- **WHEN** 设计者再次发布
- **THEN** 系统创建版本 2 并把它设为当前发布版本
- **AND** 版本 1 内容保持可追溯且不可修改

### Requirement: 菜单发布状态投影
应用菜单 MUST 按仪表盘发布状态和当前成员权限派生可见性及操作能力；未发布仪表盘只对有管理权限的成员可见，普通成员不得获得不可运行入口。

#### Scenario: 管理员查看未发布仪表盘
- **GIVEN** 仪表盘尚未发布且当前成员拥有仪表盘管理权限
- **WHEN** 成员读取应用菜单
- **THEN** 菜单包含该仪表盘并提供真实已落地的编辑、改名、移动和删除能力

#### Scenario: 普通成员查看未发布仪表盘
- **GIVEN** 仪表盘尚未发布且当前成员只有使用权限
- **WHEN** 成员读取应用菜单
- **THEN** 菜单不包含该仪表盘节点
- **AND** 直接访问运行时按不可用处理

### Requirement: 运行时 bootstrap
系统 SHALL 通过应用编码和仪表盘公开编码返回当前成员可用的运行时 bootstrap，其中包含不可变发布文档、发布版本和运行权限；不存在、未发布、已删除、跨租户或无权访问 MUST 使用稳定且不泄露信息的失败语义。

#### Scenario: 加载已发布仪表盘
- **GIVEN** 当前成员在发布范围内且有权访问仪表盘引用的数据源
- **WHEN** 应用工作区加载仪表盘运行时
- **THEN** 系统返回当前发布版本及其完整渲染文档
- **AND** 前端使用与预览相同的渲染器展示

#### Scenario: 运行时入口失效
- **GIVEN** 仪表盘不存在、未发布、已删除、属于其他租户或当前成员不在访问范围内
- **WHEN** 成员直接请求运行时 bootstrap
- **THEN** 系统返回统一的仪表盘不可用结果
- **AND** 不泄露失败目标的发布状态和归属信息

### Requirement: 应用内运行时状态恢复
应用工作区 SHALL 用通用资产路由状态恢复仪表盘菜单选中项，并 SHALL 在刷新、前进后退和从设计器返回后继续定位同一仪表盘。

#### Scenario: 刷新仪表盘运行页
- **GIVEN** 浏览器地址包含应用和仪表盘公开编码
- **WHEN** 用户刷新页面
- **THEN** 应用工作区恢复对应菜单选中态并重新加载运行时 bootstrap

#### Scenario: 从设计器返回应用
- **GIVEN** 设计者从某仪表盘进入独立设计工作区
- **WHEN** 设计者返回应用工作区
- **THEN** 应用工作区重新选中该仪表盘并展示当前已发布版本或未发布管理态提示

### Requirement: 运行时失败隔离与可观测性
单个组件查询失败 MUST 被限制在该组件范围内，仪表盘其他组件仍可使用；系统 MUST 记录仪表盘查看、查询耗时、失败类型和必要的追踪标识。

#### Scenario: 单个组件查询失败
- **GIVEN** 仪表盘包含多个组件且其中一个数据源暂时不可用
- **WHEN** 运行时加载各组件数据
- **THEN** 失败组件展示可重试错误态
- **AND** 其他组件继续加载和交互

#### Scenario: 成功查看仪表盘
- **GIVEN** 成员成功加载一个已发布仪表盘
- **WHEN** 运行时完成 bootstrap
- **THEN** 系统记录一次受去重规则约束的仪表盘查看事件及租户、应用、仪表盘和发布版本维度
