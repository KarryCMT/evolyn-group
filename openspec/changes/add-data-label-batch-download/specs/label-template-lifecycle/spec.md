# Spec Delta

## ADDED Requirements

### Requirement: 发布版本必须冻结可选输出尺寸预设

系统 SHALL 在标签模板发布版本中保存至少一个具备稳定标识、名称、物理宽高、单位和 DPI 的输出尺寸预设，并 MUST 保证历史发布版本的预设不可变；运行态显示的像素尺寸 MUST 由同一规格按统一舍入规则计算。

#### Scenario: 发布包含合法输出预设的模板
- **GIVEN** 当前草稿包含至少一个合法且与设计画布宽高比一致的输出尺寸预设
- **WHEN** 有发布权限的成员发布当前草稿
- **THEN** 系统将全部预设随发布版本冻结，并为运行态返回统一计算的物理尺寸和像素尺寸

#### Scenario: 输出预设缺失或比例不一致
- **GIVEN** 当前草稿没有合法输出预设，或预设宽高比会使设计内容发生非等比变形
- **WHEN** 成员尝试发布模板
- **THEN** 系统 MUST 拒绝发布并返回可定位的协议校验问题

#### Scenario: 历史任务使用旧发布规格
- **GIVEN** 旧发布版本已被批量任务引用，模板随后修改尺寸预设并发布新版本
- **WHEN** 旧任务执行或重试
- **THEN** 系统 MUST 继续使用旧发布版本冻结的输出预设，且新版本变更不得影响旧任务
