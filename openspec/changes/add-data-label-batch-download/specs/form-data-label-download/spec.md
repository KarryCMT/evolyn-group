# Spec Delta

## Purpose

定义表单数据管理中按所选记录安全预览并批量下载二维码标签的运行态行为，确保模板版本、输出规格、数据权限、异步任务归属和部分失败结果均稳定且可验证。

## ADDED Requirements

### Requirement: 数据管理必须按选择状态和运行时权限提供标签下载入口

系统 SHALL 仅在已认证成员具备当前表单 `batch_print` 操作权限时提供二维码标签批量下载能力，并 MUST 将当前明确勾选的记录作为下载范围。

#### Scenario: 有权限成员选择记录
- **GIVEN** 成员属于当前租户、具备当前表单 `batch_print` 权限且已勾选至少一条记录
- **WHEN** 成员打开数据管理的更多操作
- **THEN** 系统提供“下载二维码标签”入口，并显示本次选择数量

#### Scenario: 未选择记录
- **GIVEN** 成员具备 `batch_print` 权限但未勾选记录
- **WHEN** 成员查看或触发二维码标签下载入口
- **THEN** 系统 MUST 禁止创建任务并提示先选择记录

#### Scenario: 无批量打印权限
- **GIVEN** 成员已认证但不具备当前表单 `batch_print` 权限
- **WHEN** 成员访问数据管理或直接调用运行态标签接口
- **THEN** 系统 MUST 隐藏或禁用入口，并在服务端拒绝请求且不泄露模板或记录内容

### Requirement: 运行态配置必须只暴露当前表单可用的已发布模板

系统 SHALL 按当前租户和表单解析唯一有效的已发布标签模板，并返回运行态所需的模板展示信息、输出尺寸预设、批量打印可用性和模板管理能力；普通数据成员 MUST NOT 因此获得草稿或模板管理权限。

#### Scenario: 当前表单存在已发布模板
- **GIVEN** 成员具备当前表单 `batch_print` 权限，且当前租户内该表单存在有效已发布模板
- **WHEN** 成员打开批量标签下载界面
- **THEN** 系统返回当前发布版本及其输出尺寸预设，不返回模板草稿

#### Scenario: 模板不存在或未发布
- **GIVEN** 当前表单未绑定有效模板或模板尚未发布
- **WHEN** 有 `batch_print` 权限的成员打开批量标签下载界面
- **THEN** 系统返回稳定的不可用状态，前端提示先配置并发布模板且不得创建渲染任务

#### Scenario: 跨租户表单或模板
- **GIVEN** 请求中的表单或模板属于其他租户
- **WHEN** 当前租户成员请求运行态标签配置
- **THEN** 系统 MUST 按资源不可访问处理，不得返回其他租户的模板标识、版本或规格

### Requirement: 预览必须使用所选记录、发布模板和输出规格

系统 SHALL 使用当前表单的已发布模板、指定输出尺寸预设和一条成员有权批量打印的真实记录生成 SVG 预览，并返回可安全展示的截断提示。

#### Scenario: 预览当前选择中的记录
- **GIVEN** 成员具备 `batch_print` 权限、记录处于其数据范围内且输出尺寸预设有效
- **WHEN** 成员在下载界面切换到该记录
- **THEN** 系统返回使用当前发布模板与该记录数据生成的 SVG，并允许在所选记录间前后切换

#### Scenario: 记录超出数据范围
- **GIVEN** 成员具备表单级 `batch_print` 操作但目标记录不在其授权数据范围内
- **WHEN** 成员直接请求该记录预览
- **THEN** 系统 MUST 拒绝预览且不得返回记录字段或二维码内容

#### Scenario: 输出预设无效
- **GIVEN** 请求的输出预设不存在于当前发布版本
- **WHEN** 成员请求预览
- **THEN** 系统 MUST 以稳定业务错误拒绝请求且不得回退到任意尺寸

### Requirement: 批量任务必须在创建时完整校验并冻结渲染输入

系统 MUST 在创建任务前校验记录数量、唯一性、租户归属、`batch_print` 权限和每条记录的数据范围，并冻结当前发布模板版本与输出尺寸预设；任一记录无权访问时 MUST 拒绝整个任务，不得以部分成功掩盖越权输入。

#### Scenario: 创建合法批量任务
- **GIVEN** 1 至 1000 条唯一记录全部属于当前租户、当前表单并位于成员授权数据范围内
- **WHEN** 成员提交有效输出预设创建 PDF 标签任务
- **THEN** 系统返回异步任务标识，并冻结记录顺序、发布模板版本、物理尺寸和 DPI

#### Scenario: 输入包含无权记录
- **GIVEN** 批量请求中至少一条记录超出成员数据范围或属于其他租户
- **WHEN** 成员创建批量任务
- **THEN** 系统 MUST 拒绝整个请求，不创建任务和文件，且不得指出跨租户记录的具体内容

#### Scenario: 输入重复或越界
- **GIVEN** 请求包含重复记录、空记录集合或超过系统上限的记录集合
- **WHEN** 成员创建批量任务
- **THEN** 系统 MUST 以稳定业务错误拒绝请求且不入队

#### Scenario: 模板排队期间重新发布
- **GIVEN** 批量任务已经创建并冻结发布版本
- **WHEN** 模板在任务执行前或执行中发布了新版本
- **THEN** 该任务 MUST 继续使用创建时冻结的版本和输出规格，整批标签不得混用版本

### Requirement: 任务状态和下载必须受请求人归属约束

系统 SHALL 允许任务请求人查询并下载自己的任务；具备标签管理权限的当前租户成员 MAY 管理租户内任务；其他成员和其他租户 MUST NOT 访问任务详情或文件。

#### Scenario: 请求人查询任务进度
- **GIVEN** 成员创建了一个批量标签任务
- **WHEN** 该成员轮询任务状态
- **THEN** 系统返回总数、成功数、失败数、进度和稳定状态，不要求其拥有模板管理权限

#### Scenario: 同租户其他普通成员访问任务
- **GIVEN** 任务由同租户另一名成员创建，当前成员不具备标签管理权限
- **WHEN** 当前成员查询或下载该任务
- **THEN** 系统 MUST 按任务不可访问处理且不得返回任务条目或文件信息

#### Scenario: 跨租户访问任务
- **GIVEN** 任务属于其他租户
- **WHEN** 当前租户成员使用任务标识查询或下载
- **THEN** 系统 MUST 按任务不存在处理且不得泄露归属信息

### Requirement: 批量结果必须明确呈现成功、部分成功和失败

系统 SHALL 异步生成一个多页 PDF，每条成功记录对应一页，并向请求人提供可轮询的成功、部分成功或失败结果；运行期单条数据或渲染错误 MAY 产生部分成功，但不得包含未通过创建时授权校验的记录。

#### Scenario: 全部记录渲染成功
- **GIVEN** 任务中的所有记录均可按冻结输入完成渲染
- **WHEN** 任务结束
- **THEN** 系统将任务标记为成功，生成页数与记录数一致的 PDF 并允许请求人下载

#### Scenario: 运行期部分记录失败
- **GIVEN** 任务创建后部分记录因数据变化或单页渲染错误而失败
- **WHEN** 至少一条记录成功且至少一条失败
- **THEN** 系统将任务标记为部分成功，返回成功数与失败数，并提供仅包含成功记录的 PDF

#### Scenario: 全部记录失败
- **GIVEN** 任务中没有任何记录成功渲染
- **WHEN** 任务结束
- **THEN** 系统将任务标记为失败，返回安全的错误摘要且不得提供空下载文件

#### Scenario: 文件尚未就绪
- **GIVEN** 任务仍在排队或处理中
- **WHEN** 请求人请求下载
- **THEN** 系统 MUST 返回稳定的未就绪错误，不得返回不完整文件

### Requirement: 下载界面必须提供可恢复的任务交互

系统 SHALL 在下载界面展示记录序号、预览切换、输出尺寸、下载数量和任务进度，并 MUST 防止一次用户操作重复创建任务；关闭界面只停止客户端轮询，不取消已经提交的服务器任务。

#### Scenario: 防止重复提交
- **GIVEN** 用户已经提交批量渲染且创建请求尚未结束
- **WHEN** 用户再次点击下载
- **THEN** 客户端 MUST 不再创建第二个任务，并保持当前任务状态可见

#### Scenario: 关闭处理中的界面
- **GIVEN** 批量任务已由服务端接受且仍在处理
- **WHEN** 用户关闭下载界面
- **THEN** 客户端停止该界面的轮询和预览请求，服务端任务继续执行

#### Scenario: 有模板管理权限的成员修改模板
- **GIVEN** 当前成员同时拥有模板管理权限
- **WHEN** 下载界面显示已发布模板
- **THEN** 系统显示“修改二维码标签”入口并导航到当前表单的标签设置；无管理权限成员不得看到该入口
