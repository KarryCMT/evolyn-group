# Proposal

## Why

二维码标签的模板管理、单条渲染和后端异步批量渲染已经存在，但数据管理页尚未提供“勾选记录后预览并下载标签”的运行态入口；现有批量接口还沿用管理员级标签权限和固定页面规格，无法安全、准确地交付给普通数据使用者。需要补齐从表单数据权限到模板解析、尺寸选择、任务进度和文件下载的完整闭环。

## What Changes

- 在数据管理页增加“更多 → 下载二维码标签”入口，并以当前勾选记录作为批量下载范围。
- 增加运行态标签配置与真实数据预览能力，使具备表单 `batch_print` 操作权限的成员无需模板管理权限即可使用当前表单的已发布标签模板。
- 将输出尺寸预设纳入模板发布快照，批量任务按稳定预设标识冻结模板版本、物理尺寸和 DPI，前后端不再使用与实际渲染脱节的尺寸文案。
- 调整批量渲染授权：服务端按租户、表单 `batch_print` 权限和记录数据范围校验全部记录；任务请求人可查询并下载自己的任务，标签管理员可管理租户内任务。
- 增加批量下载弹窗，提供逐条 SVG 预览、记录切换、尺寸选择、渲染进度、部分成功说明和 PDF 下载；模板管理入口仅对有权限成员显示。
- 复用现有异步 Label Renderer、任务队列、对象存储和多页 PDF 能力，并补齐权限、任务归属、尺寸与前端编排测试。

非目标：本变更不重做标签设计器，不新增图片 ZIP 输出，不改变二维码扫码落地页，也不支持任意临时页面尺寸。

## Capabilities

### New Capabilities

- `form-data-label-download`: 定义数据管理中按勾选记录预览、选择发布尺寸、创建异步批量标签任务并安全下载结果的运行态行为。

### Modified Capabilities

- `label-template-lifecycle`: 发布模板必须冻结可供运行态选择的输出尺寸预设，并保证历史版本的输出规格不可变。

## Impact

- 后端：`apps/evolyn-core/internal/platform/label`、`internal/platform/form` 的权限窄端口与服务装配、标签任务查询和下载授权、Label Renderer 尺寸缩放协议。
- 前端：`apps/evolyn-web/apps/web/src/pages/form/data.vue`、数据工具栏组件、标签 API/类型、二维码设置页的输出尺寸配置与批量下载弹窗。
- 数据库：预计需要版本化迁移保存发布版本输出预设或任务冻结规格；最终以现有 JSONB 快照和任务结构核查结果为准。
- API/权限：新增按 `formCode` 定位的运行态配置与预览接口，调整批量创建/查询/下载授权；继续使用既有 `batch_print` 表单操作，不向普通成员开放 `label-templates` 管理资源。
- 文档：同步二维码打印引擎设计文档、接口说明和错误码；清理设置页中与真实渲染不一致的硬编码尺寸文案。
- 兼容性：现有已发布模板由迁移或服务端默认规则补齐稳定尺寸预设；历史渲染任务继续按其已冻结的模板快照工作。
